# BrowserOS

BrowserOS is a simple web-based desktop OS built with **React and Vite**.

It brings a retro desktop experience to your browser with apps, windows, a dock, settings, music, and more.

## Features

- 🖥️ Desktop & window management
- 📱 Mobile-friendly UI
- 📁 File Explorer
- 💻 Terminal
- ⚙️ Settings & wallpapers
- 🎵 Retro Music Player
- 📅 Calendar
- 💬 Messages
- 📖 README viewer
- 🌐 Internet browser & search
- 👥 Community guestbook

## Tech Stack

- React
- Vite
- JavaScript / JSX
- Tailwind CSS
- Lucide React
- Supabase

## Run Locally

```bash
git clone <your-repository-url>
cd browserOS
npm install
npm run dev
